## Introduction

This repository is the official implementation of our paper:

**M3Detection: Multi-Frame Multi-Level Feature Fusion for Multi-Modal 3-D Object Detection With Camera and 4-D Imaging Radar**

M³Detection is a multi-frame multi-level feature fusion framework for camera and 4-D imaging radar based 3-D object detection. It explores effective spatial and temporal fusion of complementary visual and radar information to improve 3-D object detection performance in complex driving scenarios.
